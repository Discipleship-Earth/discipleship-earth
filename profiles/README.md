## Planned profile records

As each profile is developed, its public record should include:

- The published narrative and its revision date.
- KJV references supporting biographical statements.
- Region and demographic details, identifying uncertainty where applicable.
- Image prompts, identity continuity decisions, and approved assets intended for public inspection.
- Button labels, destinations, and the order of the page's sections.
- A note identifying whether the record is a draft or a reviewed snapshot of live content.

The planned narrative format is approximately 380 words, broken into sections with buttons between them. This format remains content work in progress.
