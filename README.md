# Discipleship.Earth

The public content and development record for [Discipleship.Earth](https://discipleship.earth).

Discipleship.Earth explores biblical lives through Scripture-centered profiles, narrative, and visual storytelling rooted in the King James Bible. This repository gives readers a place to inspect the materials, sources, editorial decisions, and development process behind that work.

## How to read this repository

This is a maintainer-curated public reference. Content published here can be inspected through its files and commit history. Drafts and unfinished work should be identified explicitly, and changes should record their sources and reasons.

Scripture, editorial narrative, and artistic interpretation serve different purposes. Readers should be able to identify which they are looking at. The proposed standards describe how that distinction will be documented as content is added.

## Current scope

The original Twelve character accounts have been seeded on the live site. The index documents their initial identities and handles. Complete narratives, image prompts, approved visual assets, and profile content snapshots will be added as they are reviewed for publication here.

This repository does not automatically mirror the live site's database or media. A profile link may show content newer than the corresponding repository record. Each published snapshot should identify its review date and scope.

## Relationship to the application

The live site uses the separate [BioLync-Pro](https://github.com/joeladamski/biolync-pro) application. This repository documents content and development; it is not configured here as a deployment source. Runtime accounts, credentials, and private account information belong outside this public record.

The initial account implementation is documented in the [original Twelve seeder notes](https://github.com/joeladamski/biolync-pro/blob/13784a72f6f67293948568c62de20c3c3e46b80d/docs/DISCIPLESHIP-ACCOUNTS.md).
